\# Анализатор Списков Задач (Todos Analyzer)



Программа для валидации учебных наборов данных задач (заданных в формате JSON) и определения пользователей-лидеров, выполнивших наибольшее количество задач.



\## Структура проекта



\*   `todos.json` — Входной учебный набор данных со списком задач.

\*   `analysis.py` — Модуль, содержащий бизнес-логику: валидацию структуры и аналитические функции.

\*   `main.py` — Основной управляющий скрипт. Отвечает за безопасный ввод-вывод, обработку системных ошибок и формирование сводки.

\*   `leaders.json` — Файл результатов, генерируемый автоматически после успешного анализа.



\## Правила валидации (`analysis.py`)



Функция `validate\_todos(data)` выполняет строгую инспекцию типов данных во избежание скрытых приведений типов (например, в Python `isinstance(True, int)` возвращает `True`).



Критерии валидации:

1\. \*\*Корень:\*\* Должен быть строго списком (`list`).

2\. \*\*Элемент списка:\*\* Должен быть словарём (`dict`). Допускаются дополнительные пользовательские ключи.

3\. \*\*Поле `id`:\*\* Обязательное, уникальное в рамках всего файла, строго целое число (`type(value) is int`).

4\. \*\*Поле `userId`:\*\* Обязательное, строго целое число (`type(value) is int`).

5\. \*\*Поле `title`:\*\* Обязательное, строго непустая строка (`str`).

6\. \*\*Поле `completed`:\*\* Обязательное, строго логический тип (`type(value) is bool`).



В случае обнаружения любого несоответствия выбрасывается `ValueError` с подробным описанием проблемы, а выполнение программы останавливается без перезаписи файла результатов.



\## Логика анализа



1\.  \*\*Расчет активности (`completion\_counts`):\*\* Считает количество завершенных задач для каждого пользователя, зафиксированного в файле. Если у пользователя 0 выполненных задач, он все равно будет выведен в словаре со значением `0`.

2\.  \*\*Определение лидеров (`top\_users`):\*\* Находит пользователей с максимальным количеством `completed: true`. Возвращает отсортированный по возрастанию список ID лидеров. Если максимальное количество выполненных задач равно `0`, возвращается пустой список `\[]`.

3\.  \*\*Сохранение истории (`leaders.json`):\*\* Извлекает все ID выполненных лидерами задач, строго сохраняя их первоначальный порядок следования из файла `todos.json`.



\## Обработка ошибок



Скрипт `main.py` защищен от следующих критических ситуаций:

\*   Отсутствие файла `todos.json` на диске.

\*   Ошибки синтаксиса JSON (`json.JSONDecodeError`). Обрабатывается обособленно до базового `ValueError`.

\*   Неправильная кодировка файла (требуется строго `UTF-8`).

\*   Ошибки отсутствия прав доступа (`PermissionError`) на чтение входного или запись выходного файлов.



\## Запуск приложения



Убедитесь, что у вас установлен Python версии 3.x. Запустите главный файл через терминал:



```bash

python main.py

```



\### Пример вывода для учебного набора:

```text

\--- Сводка анализа задач ---

Всего задач обработано: 5

Распределение выполненных задач: {5: 2, 10: 2}

Лидеры по выполненным задачам (ID): \[5, 10]

ID выполненных лидерами задач: \[1, 3, 4, 5]



Результаты успешно сохранены в файл 'leaders.json'.

```
